## Project Overview :rocket:

English Travels was created as my **engineering thesis project** at DSW Ideis.  
It is a **single-player, educational 3D adventure game** with a **first-person perspective**.

The player travels abroad to take care of their aunt's house. The aunt leaves letters with small tasks, like shopping or going to a restaurant.
While exploring, the player learns **basic English words (A1 level)** by interacting with items and talking to NPCs.
Later, the words can be practised in a **notebook** with flashcards and mini-games.

The game interface and translations are in Polish.

The project was developed in **Unreal Engine 5 using C++ and Blueprints**.

---

## Features :fire:

- First-person movement and exploration
- Story tasks from the aunt's letters
- Two locations to explore: shop and restaurant
- Interactive items with English words, Polish translations and English pronunciation
- Dialogues with NPCs (translation after clicking the sentence)
- Story quiz at the end of each location
- Notebook with word statistics and knowledge level (0–12 points)
- Flashcards and smart review (words come back after some time)
- Mini-games: Quiz, Memory and Writing
- Practice by word categories
- Own notes in the notebook
- Autosave and **Continue** / **New game** options

---

## Controls :video_game:

- **W, A, S, D** – move
- **Mouse** – look around
- **E** – interact (items, NPCs, letters, doors, desk)
- **Left mouse button** – click buttons in the interface
- **Esc** – open pause menu

## Installation :magic_wand:

### Playing the game

The game runs on **Windows 11 (64-bit)**.  
It was tested on: Intel Core i5-9600K, NVIDIA GeForce RTX 2060 (6 GB), 16 GB RAM, 2560×1440.

1. Download the game from [**GitHub Releases**](https://github.com/Lesiiaa/EnglishTravels/releases)
2. Extract the downloaded ZIP archive
3. Run **EnglishTravels.exe**
4. Enjoy the game!

The progress is saved automatically in `%LOCALAPPDATA%\EnglishTravels\Saved\SaveGames\`.
